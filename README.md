# Cheating Daddy

A real-time AI assistant that provides contextual help during video calls, interviews, presentations, and meetings using screen capture and audio analysis. Answers are generated by **DeepSeek**.

> [!NOTE]
> Use the latest macOS and Windows versions; older versions have limited support.

> [!NOTE]
> During testing it won't answer if you ask something directly — simulate the interviewer asking a question, and it will answer.

## Features

- **DeepSeek-powered answers**: Text responses come from the DeepSeek chat API
- **Screen & audio capture**: Analyses what you see and hear for contextual responses
- **Multiple profiles**: Interview, Sales Call, Business Meeting, Presentation, Negotiation, Exam
- **Transparent overlay**: Frameless always-visible window, movable with keyboard shortcuts
- **Click-through mode**: Make the window ignore mouse clicks when needed
- **Auto-write**: Types the current answer straight into whichever app is focused — no copy/paste
- **Cross-platform**: macOS, Windows, and Linux (Linux is best-effort)

## Setup

Requires **Node.js 18+** (20+ recommended) and npm.

1. **Get a DeepSeek API key**: <https://platform.deepseek.com/api_keys>
2. **Install dependencies**: `npm install`
3. **Run the app**: `npm start`

**Windows:** run the commands from PowerShell or Command Prompt. Auto-write uses the built-in PowerShell `SendInput` helper (no extra install); it is launched with `-ExecutionPolicy Bypass`, so no policy changes are needed.

## Usage

1. Paste your DeepSeek API key in the main window (Config → DeepSeek)
2. Leave **Live audio (Gemini)** disabled when using DeepSeek for screen-text responses. A Gemini key is only required when Live Audio is enabled.
3. Choose your profile and language in settings
4. Click "Start Session" to begin
5. Position the window using the keyboard shortcuts
6. The AI responds in real time as the interviewer speaks

## Auto-Write

Types the current answer into the focused application, character by character.

- **Type**: `Option + \` on macOS, `Alt + \` on Windows/Linux (or the Auto-Write button next to "Analyze Screen")
- **Pause / resume**: press the same shortcut again. On macOS you can also **hold Option alone for ~0.6 s** while it types — this needs no shortcut and cannot exit fullscreen
- **Cancel**: `Cmd + Option + D` on macOS, `Alt + D` on Windows
- **macOS** requires Accessibility permission (System Settings → Privacy & Security → Accessibility)

Code blocks are typed with comments stripped and de-indented so auto-indenting editors don't drift; prose is stripped of markdown. Speed defaults to 150 WPM and can be changed with `autoWriteSpeed` in the preferences file (`150wpm`, `slow`, `realistic`, `fast`, `turbo`, or a number).

## Keyboard Shortcuts

- **Move window**: `Cmd/Ctrl + Arrow Keys`
- **Click-through**: `Cmd/Ctrl + M`
- **Show/hide**: `Cmd/Ctrl + \`
- **Ask next step (screenshot)**: `Cmd/Ctrl + Enter`
- **Previous / next response**: `Cmd/Ctrl + [` and `Cmd/Ctrl + ]`
- **Scroll response**: `Cmd/Ctrl + Shift + Up/Down`
- **Auto-write answer**: `Cmd/Ctrl + Option/Alt + W`
- **Cancel auto-write**: `Cmd/Ctrl + Option/Alt + D`
- **Emergency erase**: `Cmd/Ctrl + Shift + E`
- **Send message**: `Enter`

All shortcuts are editable in Customize.

## Audio Capture

- **macOS**: [SystemAudioDump](https://github.com/Mohammed-Yasin-Mulla/Sound) for system audio
- **Windows**: Loopback audio capture
- **Linux**: Microphone input

## Requirements

- Electron-compatible OS (macOS, Windows, Linux)
- DeepSeek API key
- Screen recording and microphone permissions
- Accessibility permission on macOS (for auto-write)
